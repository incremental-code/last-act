last.act

A tiny, readable reimplementation of React's core ideas.

Components, useState, useEffect, useContext, and a DOM reconciler — under 500 lines, no build step, plain ES modules. Read last.act.js end to end and you've seen the spine of React. Below: the whole file, with its comments lifted out and set alongside the code they describe.

A component is a plain function that returns an element — the same { type, props } description JSX compiles to.
